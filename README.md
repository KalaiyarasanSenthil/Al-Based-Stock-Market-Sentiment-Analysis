# Al-Based-Stock-Market-Sentiment-Analysis
AI-driven sentiment analysis on financial news for a NASDAQ-listed stock. Classifies news as positive/neutral/negative using Word2Vec &amp; Sentence Transformer embeddings (BAAI/bge-base, MiniLM), then compares Random Forest vs Neural Network models via Accuracy, Precision, Recall &amp; F1-Score to find the best sentiment classifier.
